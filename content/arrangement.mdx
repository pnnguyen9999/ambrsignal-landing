# Arrangement

Arrange mode turns loops into a longer piece of music. Instead of playing one pattern forever, AMBR Signal can chain patterns across tracks.

The arrangement layer answers this question:

What should each track play next?

## Track pattern chains

Each track can have its own pattern chain.

Example:

`Track 1: Pattern 1 -> Pattern 4 -> Pattern 3`

`Track 2: Pattern 1 -> Pattern 2 -> Pattern 2`

`Track 3: Pattern 3 -> Pattern 4 -> Pattern 1`

This is useful because drums, bass, melody, and texture do not always need to change at the same moment.

## Building an arrangement

A practical Arrange workflow:

1. Select a track.
2. Choose a bank.
3. Choose a pattern.
4. Place the pattern in the timeline.
5. Repeat for the next position.
6. Move to another track and build its chain.

The result is a song map made from existing patterns.

## Simple song structure

A simple arrangement can be made with four pattern roles:

- Intro: fewer elements.
- Main: the full groove.
- Break: reduced drums or muted bass.
- Fill: a short transition into the next section.

Example:

`Intro -> Main -> Main Variation -> Break -> Main -> Fill`

This keeps the arrangement readable while still giving the performance a shape.

## Arrangement vs sequencing

Sequencing edits what happens inside a pattern.

Arrangement decides which patterns play over time.

If one bar feels wrong, edit the sequencer. If the whole song feels too repetitive, edit the arrangement.

## Arrangement vs live performance

Arrange mode can play a planned structure. Performance FX can still be used on top of that structure.

This means you can prepare the song shape in advance, then perform transitions, drops, and glitches live.
