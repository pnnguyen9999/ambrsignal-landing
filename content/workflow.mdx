# Workflow Example

This example shows one complete AMBR Signal session. It starts with a blank project and ends with a playable arrangement using FX Banks.

## Goal

Create a simple four-track groove:

- Track 1: drums.
- Track 2: bass.
- Track 3: chord or melodic part.
- Track 4: texture or sample.

The final result should have multiple patterns, a basic arrangement, and a few performance FX choices.

## Step 1: Build the sounds

Open Instrument for each track.

For Track 1, load drum samples or use short synthesized percussion sounds.

For Track 2, choose a saw or square waveform for bass. Set a short attack and a controlled release.

For Track 3, choose a softer waveform or sample for chords and melody. Use a longer release if the part should feel wide.

For Track 4, load a texture, noise layer, vocal cut, or field recording.

At this stage, do not over-design. The sounds only need to be clear enough to sequence.

## Step 2: Write the first pattern

Open Sequencer and choose Bank A, Pattern 1.

Write a 16-step pattern:

- Track 1: place the main drum hits.
- Track 2: add a bass line around the kick.
- Track 3: add a simple chord or melodic phrase.
- Track 4: add one or two texture triggers.

Keep Pattern 1 simple. It should be the main groove.

## Step 3: Create variations

Copy or build additional patterns in the same bank.

Suggested pattern roles:

- Pattern 1: main groove.
- Pattern 2: groove with more movement.
- Pattern 3: breakdown with fewer drums.
- Pattern 4: fill or transition.

Use velocity, probability, and parameter locks to make variations without changing the whole sound.

## Step 4: Add time signature variation

Keep the main drum and bass tracks in 4/4.

Try a different cycle on Track 3 or Track 4. A shorter or odd-feeling phrase can make the loop evolve over time.

For example, keep drums on a 16-step loop, but let a texture phrase cycle differently. This creates motion without needing a long sequence.

## Step 5: Arrange the patterns

Open Arrange mode.

Create a simple pattern chain:

`Intro -> Main -> Variation -> Break -> Main -> Fill`

Example:

- Track 1: Pattern 3 -> Pattern 1 -> Pattern 2 -> Pattern 3 -> Pattern 1 -> Pattern 4.
- Track 2: Pattern 3 -> Pattern 1 -> Pattern 2 -> Pattern 3 -> Pattern 1 -> Pattern 1.
- Track 3: Pattern 3 -> Pattern 1 -> Pattern 2 -> Pattern 2 -> Pattern 1 -> Pattern 4.
- Track 4: Pattern 1 -> Pattern 1 -> Pattern 2 -> Pattern 3 -> Pattern 2 -> Pattern 4.

The arrangement does not need to be long. It only needs enough structure to move beyond a single loop.

## Step 6: Prepare FX Banks

Open FX and prepare a few performance banks.

Example:

- FX Bank 1: gentle filter sweep.
- FX Bank 2: stutter fill.
- FX Bank 3: vinyl stop into a break.
- FX Bank 4: scratch or glitch moment.
- FX Bank 5: delay or reverb wash.

Use FX Bank 1 for subtle transitions and save the more dramatic banks for section changes.

## Step 7: Perform

Start playback from the arrangement.

Let the first section play without too many changes. Use filter moves to introduce energy, then trigger stutter or vinyl effects near transitions.

A good performance should feel intentional:

- Let the groove breathe.
- Use FX at phrase boundaries.
- Return to the main pattern after dramatic gestures.
- Keep one or two FX Banks as surprises.

AMBR Signal is designed so the planned structure and live performance can work together. The arrangement gives the song a path. FX Banks let you play that path in real time.
