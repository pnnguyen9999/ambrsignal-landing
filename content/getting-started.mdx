# Getting Started

Add Markdown or MDX files to the `content` directory. Nextra publishes them under `/documents`.

## File routing

- `content/index.mdx` renders at `/documents`.
- `content/getting-started.mdx` renders at `/documents/getting-started`.
- `content/_meta.ts` controls the sidebar labels and order.
